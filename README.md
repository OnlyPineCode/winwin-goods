# 物料箱

iOS 风格的单文件网页应用，用于管理线下追星物料与互换记录。零依赖、无需服务器、数据全部存本机。

## 功能

- **物料库** — 物料台账（图片/类别/多活动归属/标签/成本），余量可手动编辑（= 已完成 − 换出 + 换入 + 调整值），支持活动/类别/标签筛选与按活动/类别分组
- **制作** — 按活动汇总制作进度，工厂/美工/画师对接信息，步进器快速更新完成数
- **互换记录** — 以互换对象为一笔，给出/收到明细 + 状态流转（待面交/待寄出/已完成），按活动/物料/人三种视图，按物料统计换出/换入/净变化
- **设置** — 活动与类别/制作状态自定义管理、JSON 导出/导入、GitHub 仓库云备份（配置仓库后一键提交/恢复备份文件）

## 使用

线上访问：开启 GitHub Pages 后直接用手机浏览器打开 `https://<用户名>.github.io/<仓库名>/`，Safari 里「添加到主屏幕」即可当 App 使用。

数据保存在浏览器本地（IndexedDB），换设备请使用 **设置 → 导出备份文件 / GitHub 云端备份**。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录所有文件（含 `index.html`）推上去：

```bash
git init
git add .
git commit -m "init: 物料箱"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

2. 仓库 **Settings → Pages → Branch** 选 `main` / `(root)`，保存
3. 一分钟后访问 `https://<用户名>.github.io/<仓库名>/`

## 隐私

- 所有数据只存在你自己的浏览器里，不会上传到任何服务器
- GitHub 备份需要你自己配置一个仓库（建议私有）+ 有 Contents 读写权限的 Token，备份以提交形式写入该仓库；Token 只保存在本机

# 物料箱

iOS 风格的单文件网页应用，用于管理线下追星物料与互换记录。零依赖、无需服务器、数据全部存本机。

## 功能

- **物料箱** — 物料台账（图片/类别/多活动归属/标签/成本），余量可手动编辑（= 已完成 − 换出 + 换入 + 调整值），支持活动/类别/标签筛选与按活动/类别分组。详情页字段行可点击快捷修改
- **制作** — 按活动汇总制作进度，工厂/美工/画师对接信息，步进器快速更新完成数
- **互换** — 以互换对象为一笔，给出/收到明细 + 状态流转（状态可自定义），按活动/物料/人三种视图，按物料统计换出/换入/净变化。日期随所选活动自动带出（活动无日期则取当天），仍可手动修改。快递单号仅在「邮寄态」状态时展示（见下）。详情页字段行可点击快捷修改
- **设置** — 活动与类别 / 制作状态 / 互换状态自定义管理、JSON 导出/导入、GitHub 仓库云备份（配置仓库后一键提交/恢复备份文件）

## 界面行为

- 页面下滑时，顶部只固定标题条（含状态栏安全区），搜索框与筛选项随内容滚走；底部标签栏始终固定
- 详情/表单弹层为「固定头 + 可滚内容 + 固定底栏」，主操作按钮不随内容滚动，长列表下始终可达
- 字段快捷修改弹层不关闭底层详情，保存后原地刷新
- **保存即时落盘**：快捷编辑、表单保存、状态流转等提交动作立即写入本地库，不受节流延迟影响；页面切后台/关闭时（`pagehide`/`visibilitychange`）自动兜底刷盘，避免 iOS 切 App 丢数据

### 批量操作

物料箱、制作、互换三个列表都支持多选后批量处理。

| 操作 | 说明 |
|---|---|
| 进入多选 | 点标题栏「选择」，或**长按任意一条**记录；切换 tab 会自动退出 |
| 勾选 | 多选态下点整行即勾选；底部工具条提供「全选 / 取消全选」 |
| 修改状态 | 底部「修改状态」按钮；物料走制作状态，互换走配置的互换状态；互换改为非邮寄态时会清空快递单号 |
| 批量删除 | 二次确认后删除；删物料会同步移除互换记录里引用该物料的明细 |

> 长按进入多选在触屏上会带一次轻震动反馈；滑动超过 10px 视为滚动，不会误触发。

### 自定义互换状态

设置 → 物料选项 → **互换状态管理**，与制作状态管理同构：换色、改名、增删。

| 规则 | 说明 |
|---|---|
| 排序 | 列表与「按人」分组都按配置顺序排列 |
| 「完成」按钮 | 固定跳到名为 **「已完成」** 的状态；若配置里没有这个状态，才回落到最后一个。把「已取消」之类追加到末尾不会影响它 |
| 改名 | 已有互换记录的状态名自动同步迁移，筛选条件同步更新；重名会被拒绝 |
| 删除 | 若还有记录在用该状态则**禁止删除**，提示记录条数；至少要保留一个状态 |
| 快递单号 | 状态对象内部带 `mail` 标记，标记随状态走，所以「待寄出」改名成「已寄出」后单号仍正常展示。旧数据没有该标记时回退到名字判断，因此旧备份/旧配置不受影响 |
| 兼容 | 备份 JSON 增加 `exStatuses` 字段；导入旧备份（无该字段）时自动回落默认三态，非法状态值的记录回落第一个状态 |

## 使用

线上访问：开启 GitHub Pages 后直接用手机浏览器打开 `https://<用户名>.github.io/<仓库名>/`，Safari 里「添加到主屏幕」即可当 App 使用。

数据保存在浏览器本地（IndexedDB），换设备请使用 **设置 → 导出备份文件 / GitHub 云端备份**。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录所有文件（含 `index.html`）推上去：

```bash
git init
git add .
git commit -m "init: 物料箱"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

2. 仓库 **Settings → Pages → Branch** 选 `main` / `(root)`，保存
3. 一分钟后访问 `https://<用户名>.github.io/<仓库名>/`

## 隐私

- 所有数据只存在你自己的浏览器里，不会上传到任何服务器
- GitHub 备份需要你自己配置一个仓库（建议私有）+ 有 Contents 读写权限的 Token，备份以提交形式写入该仓库；Token 只保存在本机
